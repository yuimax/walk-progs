# walk-progs

* Go言語 + [walk](https://github.com/lxn/walk) による Windows GUI プログラミングの練習

+ ここでは walk/declarative を利用せず、walk のみでコーディングする
+ declarative を使う例はこちら＞ https://github.com/yuimax/decl-progs

## 使用ツール

* **go.exe** --- https://go.dev/doc/install
* **make.exe** --- https://gnuwin32.sourceforge.net/packages/make.htm
* **goversioninfo.exe** --- https://github.com/josephspurrier/goversioninfo
* **rm.exe** --- [Git for Windows](https://gitforwindows.org/) に付いてくるやつでよい
